# Relatórios congelados

Cada arquivo aqui é uma foto do projeto num momento, guardada junto com a tag de
release correspondente. **Não são atualizados.** Se o projeto andou, gera-se um
relatório novo com a data nova — o antigo continua valendo como registro do que se
sabia naquele dia.

São páginas HTML autossuficientes: sem fonte externa, sem script remoto, sem imagem de
fora. Abrem offline, com dois cliques, em qualquer navegador. Servem para mostrar o
andamento a quem não vai ler markdown no GitHub — a diretoria da APPD, por exemplo.

## O que o relatório de 2026-08-05 registra

Varredura das 15 páginas do site atual, o cruzamento entre os serviços divulgados e as
opções do formulário oficial, as nove páginas de conteúdo escritas para o site novo, a
correção do dado sem lastro no texto do Artesão da Inclusão, quatro riscos de dado
pessoal e as cinco perguntas para a reunião com a associação.
